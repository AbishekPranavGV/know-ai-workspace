> **Next-generation enterprise workspace platform bridging personal knowledge management, team collaboration, autonomous task scheduling, and secure file vaults.**

---

## 🌟 Key Functional Pillars

1. **Intelligent Second-Brain & Document Vault**:
   - Structured note-taking, Markdown sync, flashcard spaced repetition learning engine, and encrypted document storage.
2. **Unified Operational Dashboard**:
   - Real-time productivity analytics, executive goal tracking, agile task kanban board, and interactive team calendar.
3. **Multi-Channel Communications**:
   - Real-time workspace chat, context-aware AI assistant integration, and automated event notifications.
4. **Enterprise Security & Compliance**:
   - Session auditing, granular RBAC permissions, exportable activity audit trails, and multi-tenant isolation.
5. **Universal Command Palette (`Cmd + K`)**:
   - Global search across notes, tasks, team members, integrations, and operational files.

---

## 🏗️ Architecture & Technology Stack

- **Framework**: Next.js 15 (App Router, Server Actions, Dynamic Route Handlers)
- **UI / Design System**: Tailwind CSS, Radix UI primitives, Lucide Icons, Dark/Light Mode Theme Provider
- **Database & ORM**: Prisma ORM, LibSQL / Turso distributed database adapter, SQLite local fallback
- **Authentication**: NextAuth.js / Auth.js with Prisma Adapter & session management
- **State & Forms**: React Hook Form, Zod schema validation

---

## 🚀 Quickstart & Installation

```bash
git clone https://github.com/AbishekPranavGV/know-ai-workspace.git
cd know-ai-workspace
npm install
npx prisma generate
npx prisma db push
npm run dev
```

Visit `http://localhost:3000` to launch the workspace console.
